# Learn Letters: синхронизация через Yandex Cloud

Приложение остаётся **local-first**: сначала прогресс сохраняется в браузере ребёнка, затем копия отправляется в Yandex Cloud. Если интернет пропал, занятие не ломается; при следующем изменении прогресса приложение попробует синхронизацию снова.

## Что уже подготовлено

- `index.py` — одна Cloud Function: регистрация ученика по коду класса, сохранение прогресса, вход учителя по PIN и получение всего класса.
- `schema.yql` — пять таблиц для YDB Serverless.
- `openapi.yaml` — шаблон API Gateway.
- `requirements.txt` — библиотека YDB для Python.
- `bootstrap_teacher.py` — однократное безопасное создание учителя и класса.
- `learn-letters-function.zip` — готовый архив для загрузки в Cloud Functions (создаётся локально и не публикуется в GitHub).

PIN не хранится открытым текстом: сервер сохраняет PBKDF2-SHA256-хеш с индивидуальной солью. `AUTH_SECRET` и `BOOTSTRAP_SECRET` должны находиться только в настройках Cloud Function.

## Перед началом

Нужны аккаунт Yandex Cloud, каталог и платёжный аккаунт со статусом `ACTIVE` или пробным периодом. Все ресурсы ниже создавайте **в одном каталоге** и регионе.

## 1. Создать YDB Serverless

1. Откройте [console.yandex.cloud](https://console.yandex.cloud/).
2. В верхней панели выберите нужный каталог.
3. Откройте **Managed Service for YDB**.
4. Нажмите **Создать базу данных**.
5. Имя: `learn-letters-db`.
6. Тип базы: **Serverless**.
7. Нажмите **Создать базу данных** и дождитесь статуса `Running`.
8. Откройте созданную базу. Сохраните в заметки два значения со страницы **Обзор**:
   - **Эндпоинт** — начинается с `grpcs://`;
   - **Путь базы данных** — начинается с `/ru-central1/`.
9. Откройте вкладку **Навигация**, нажмите **Новый SQL-запрос**.
10. Откройте локальный файл `cloud/yandex/schema.yql`, скопируйте его полностью, вставьте в редактор и нажмите **Выполнить** один раз.
11. В списке должны появиться таблицы `teachers`, `groups`, `students`, `group_members`, `student_snapshots`.

## 2. Создать сервисный аккаунт

1. В меню каталога откройте **Сервисные аккаунты** → **Создать сервисный аккаунт**.
2. Имя: `learn-letters-sync-sa`.
3. Создайте аккаунт и скопируйте его **ID** в заметки.
4. Назначьте ему две роли:
   - `ydb.editor` — чтение и запись прогресса в YDB;
   - `functions.functionInvoker` — вызов приватной функции через API Gateway.

Для небольшого учебного проекта это один понятный сервисный аккаунт. Секретный ключ сервисного аккаунта создавать и скачивать не нужно.

## 3. Создать Cloud Function

1. Откройте **Cloud Functions** → **Создать функцию**.
2. Имя: `learn-letters-sync`.
3. Нажмите **Создать**.
4. Откройте функцию → **Создать версию**.
5. Среда выполнения: **Python 3.12**.
6. Способ загрузки: **ZIP-архив**.
7. Загрузите локальный файл `cloud/yandex/learn-letters-function.zip`.
8. Точка входа: `index.handler`.
9. Таймаут: `20 секунд`.
10. Память: `256 МБ`.
11. Сервисный аккаунт: `learn-letters-sync-sa`.
12. Добавьте переменные окружения (без кавычек):

```text
YDB_ENDPOINT=grpcs://...значение из шага 1...
YDB_DATABASE=/ru-central1/...значение из шага 1...
AUTH_SECRET=длинная_случайная_строка_не_короче_32_символов
BOOTSTRAP_SECRET=другая_длинная_случайная_строка
ALLOWED_ORIGIN=https://itstxaviers-svg.github.io
```

На Mac две разные безопасные строки можно получить в Terminal командами `openssl rand -hex 32` (запустите два раза). Не присылайте их в чат и не добавляйте в GitHub.

13. Нажмите **Сохранить изменения** / **Создать версию**.
14. На странице функции скопируйте **ID функции** в заметки.

## 4. Создать API Gateway

1. Откройте **API Gateway** → **Создать API-шлюз**.
2. Имя: `learn-letters-api`.
3. Откройте локальный `cloud/yandex/openapi.yaml`.
4. Замените `<FUNCTION_ID>` на ID функции из шага 3.
5. Замените `<SERVICE_ACCOUNT_ID>` на ID сервисного аккаунта из шага 2.
6. Скопируйте весь изменённый YAML в поле **Спецификация**.
7. Нажмите **Создать**.
8. Откройте шлюз и скопируйте его служебный домен вида `https://....apigw.yandexcloud.net`.
9. Проверьте в браузере адрес:

```text
https://....apigw.yandexcloud.net/health
```

Ожидаемый ответ: `{"ok": true, "service": "learn-letters-sync"}`.

## 5. Один раз создать учителя и класс

1. Откройте Terminal.
2. Выполните:

```bash
cd "/Users/sophie/Downloads/learn letters"
python3 cloud/yandex/bootstrap_teacher.py
```

3. Скрипт по очереди попросит:
   - URL шлюза из шага 4;
   - `BOOTSTRAP_SECRET` из настроек функции;
   - PIN учителя: `19071970`;
   - имя учителя;
   - название класса, например `2A`;
   - код класса латиницей, например `LETTERS-2A`.
4. Должно появиться `Готово` и введённый Join Code.
5. После успешного создания учителя вернитесь в настройки версии функции и **замените `BOOTSTRAP_SECRET` на новую случайную строку**. Старый секрет больше не понадобится. Это закрывает повторную первоначальную настройку.

## 6. Соединить опубликованный сайт с облаком

1. Откройте репозиторий `itstxaviers-svg/HPLetters` на GitHub.
2. Перейдите **Settings** → **Secrets and variables** → **Actions**.
3. Откройте вкладку **Variables** → **New repository variable**.
4. Name: `VITE_YANDEX_API_URL`.
5. Value: URL шлюза **без `/` в конце**.
6. Сохраните.
7. Откройте **Actions** → workflow **Deploy Learn Letters to GitHub Pages** → **Run workflow** → **Run workflow**.

После развёртывания в верхней части приложения вместо `Local progress saved` появится `Cloud progress saved` после успешной отправки.

## 7. Как пользоваться

- Ребёнок вводит имя и **точный код класса**, например `LETTERS-2A`.
- Профиль сразу остаётся локально. При наличии интернета он регистрируется в облаке и прогресс синхронизируется примерно через секунду после изменения.
- Учитель на любом устройстве открывает сайт → **Teacher area** → вводит PIN `19071970`.
- Кабинет получает из облака список всех учеников этого класса, попытки, точность, награды и рейтинг.
- Ребёнок не видит общий рейтинг класса; у него остаются только собственные награды.

## Если что-то не работает

- `Class not found` — ребёнок ввёл не тот Join Code.
- `Teacher PIN is not correct` — неверный PIN либо учитель ещё не создан шагом 5.
- `Cloud service error` — проверьте `YDB_ENDPOINT`, `YDB_DATABASE`, роль `ydb.editor` и журналы Cloud Function.
- `Saved locally • cloud offline` — локальные данные не потеряны; проверьте интернет, адрес `VITE_YANDEX_API_URL` и `/health`.
- После изменения GitHub Variable обязательно заново запустите workflow, потому что адрес API встраивается во время сборки сайта.
